常见问题

FAQ

SeasAGI 和直接调用 API 有什么区别？How is SeasAGI different from calling APIs directly?▼
直接调用 API 需要手动管理多个 Key、处理失败重试、选择最优模型。SeasAGI 自动完成这一切：统一网关、会话粘滞路由、动态 429 惩罚降级、成本优化引擎、全链路可观测，一个工具搞定所有管理。
Direct API calls require manually managing multiple keys, handling failures, and choosing the optimal model. SeasAGI automates all of this: unified gateway, session sticky routing, dynamic 429 penalty, cost optimization engine, and full observability — all in one tool.
API Key 安全吗？Are my API keys secure?▼
API Key 仅本地存储在 macOS Keychain 中，校验使用常量时间比较防时序攻击，请求直接由客户端发往 Provider，永不经过 SeasAGI 云端，你拥有完全的控制权。
API keys are stored locally in macOS Keychain. Validation uses constant-time comparison to prevent timing attacks. Requests go directly from the client to providers, never through SeasAGI cloud. You have full control.
会话粘滞是什么？为什么需要？What is session sticky routing?▼
会话粘滞基于首条用户消息的 SHA1 哈希，将同一对话的后续请求自动路由到同一模型，防止多轮对话中途切换模型导致上下文断裂或幻觉。30 分钟 TTL 自动过期。
Session sticky routing uses SHA1 hash of the first user message to route all subsequent requests in the same conversation to the same model, preventing context breaks or hallucinations from mid-conversation model switches. 30-min TTL auto-expires.

SeasAGI is the only solution with a native desktop client + local gateway proxy (direct to providers, no server bottleneck); the only one with full multi-tenant + Stripe payment; the only one with 6 protocol translators + OAuth PKCE. It also incorporates FreeLLMAPI's dynamic 429 penalty, sort presets, and Playground, plus adds session sticky, key health check, per-key cooldown and other enterprise features.

Token 市场是什么？What is the Token Market?▼
Token 市场是 SeasAGI 客户端内置的 API Key 交易平台。用户可以将闲置的 API Key 上架出售（支持一口价和折扣两种模式），其他用户可浏览市场、查看卖家信息、扫码完成交易。平台收取 10% 佣金，卖家获得 90% 收益。交易二维码带 HMAC 签名和 5 分钟有效期，企业版提供完整的管理后台和风控审计。
The Token Market is a built-in API Key trading platform in the SeasAGI client. Users can list unused API keys for sale (fixed price or discount mode), and other users can browse the marketplace, view seller info, and complete trades via QR code scanning. The platform charges a 10% commission, and sellers receive 90% of the proceeds. Trade QR codes include HMAC signatures with 5-minute expiry. The Enterprise edition provides a full admin dashboard with risk control and audit logging.
